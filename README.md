# ゼロから始める生成AI

## ラボマニュアル

### はじめに

この演習資料は、研修テキスト「ゼロから始める生成AI」と組み合わせて使用します。

演習では、Microsoft 365のライセンスに付帯する **Microsoft Copilot Chat** を使用します。生成AIを初めて使う方が、文章や画像の生成、プロンプトの改善、安全な確認、業務文書の作成を順番に体験する内容です。

## 使用する環境

- Microsoft EdgeまたはGoogle Chrome
- 講師から指定されたMicrosoft 365の職場または学校アカウント
- [Microsoft 365 Copilot Chat](https://m365.cloud.microsoft/chat)

> **重要**
>
> - 個人用Microsoftアカウントではなく、講師が指定したアカウントを使用してください。
> - 組織の設定により、利用できる機能や画面の表示が異なる場合があります。

## 演習の進め方

各ラボには、コピーして使えるプロンプトを掲載しています。

ラボ 01〜04bは、次の3つで構成されています。

- **基本課題**：全員が取り組む内容です。まずはこちらを進めます。
- **チャレンジ課題**：基本課題を早く終えた場合に取り組む任意の内容です。
- **振り返り**：生成結果を見ながら、使った手法と確認すべき点を整理します。

1. プロンプトをコピーします。
2. Copilot Chatの入力欄へ貼り付けます。
3. 送信し、生成結果を確認します。
4. 改善後のプロンプトや追加の指示を試します。
5. 「確認ポイント」に書かれた項目を画面上で確かめます。

比較するときは、毎回次の順に見ます。①追加した条件は何か、②回答のどこが変わったか、③元の条件や事実が残っているか。各ラボの「確認ポイント」「期待する変化」「条件の影響」は、正解文の暗記ではなく、この比較の目安です。

## 演習を始める前の注意

- 生成AIの回答は毎回同じになるとは限りません。
- AIが自然な文章で回答しても、内容が正しいとは限りません。
- 実在する顧客情報、個人情報、パスワード、社外秘情報は入力しないでください。
